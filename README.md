# Dimmelo con una citazione

Mini social studio per `@dimmeloconunacitazione`.

## Obiettivo

Creare, verificare, impaginare e preparare automaticamente contenuti Instagram, con un'interfaccia semplice utilizzabile da iPhone.

## Fase 1

- Generazione di citazione + autore + caption + hashtag
- Anteprima grafica 1080x1350
- Approvazione / rigenerazione
- Archivio locale delle citazioni usate
- Nessuna chiave API salvata nel repository

## Sicurezza

Non inserire mai API key nel codice o nei commit. Le chiavi per servizi esterni verranno aggiunte successivamente tramite GitHub Secrets o, per il prototipo locale, inserite temporaneamente dall'utente nel browser senza salvarle nel repository.

## Stato

Prototipo iniziale. La pubblicazione Instagram verrà aggiunta dopo aver validato generazione e grafica.
